# ВольтаПро Сервіс — Корпоративний сайт із керуванням зверненнями

Вебсистема підприємства з публічною частиною (каталог послуг, приймання звернень, перевірка статусу за номером і кодом доступу) та закритим кабінетом менеджера (оброблення звернень, розмежування прав доступу, історія статусів, контроль строків опрацювання SLA у робочих днях та звіт про прострочені заявки).

## Стек і вимоги до середовища
* **Середовище виконання:** Node.js `v22.5+` або `v24+` / `v26` (перевірено на `Node.js v26.13.1`, `npm 11.20.0`, Windows 11 Pro).
* **База даних:** вбудований модуль `node:sqlite` (SQLite з WAL-режимом та зовнішніми ключами).
* **Фронтенд:** семантичний HTML5, CSS3, ES-модулі JavaScript, локально підключений Bootstrap 5.
* **Контейнеризація (опційно):** `Dockerfile` та `docker-compose.yml`.

## Структура проєкту
* `src/` — серверний код (`domain/`, `repositories/`, `services/`, `routes/`, `middleware/`, `db/`, `app.js`, `server.js`).
* `public/` — клієнтський інтерфейс (`index.html`, `status.html`, `manager.html`, `css/`, `js/`).
* `migrations/` — SQL-міграції схеми даних (`001_init.sql`).
* `tests/` — модульні, інтеграційні, навантажувальні тести та тест обсягом даних.
* `docs/` — OpenAPI-специфікація (`openapi.yaml`) та схеми.
* `evidence/` — збережені протоколи перевірок і скріншоти.

## Встановлення та штатний запуск (Windows / Linux / macOS)

1. Встановіть залежності у каталозі проєкту:
   ```bash
   npm install
   ```
2. Скопіюйте приклад конфігурації (за потреби змініть порт чи шлях до БД):
   ```bash
   cp .env.example .env
   ```
3. Застосуйте міграції та завантажте синтетичний демонстраційний набір даних:
   ```bash
   npm run migrate
   npm run seed
   ```
4. Запустіть вебсервер:
   ```bash
   npm start
   ```
5. Відкрийте у браузері (Google Chrome):
   * Публічний сайт і форма звернення: `http://localhost:3000/`
   * Перевірка статусу заявки клієнтом: `http://localhost:3000/status`
   * Кабінет менеджера: `http://localhost:3000/manager`
   * Перевірка стану (healthcheck): `http://localhost:3000/api/health`

### Зупинка сервера
Натисніть `Ctrl + C` у терміналі, де запущено процес `node src/server.js`.

## Запуск у Docker (альтернативний спосіб)
```bash
docker compose up --build -d
```
Зупинка:
```bash
docker compose down
```

## Тестування
* Модульні та інтеграційні тести:
  ```bash
  npm test
  ```
* Тест обсягом даних (100, 1 000 та 10 000 записів):
  ```bash
  npm run test:volume
  ```
* Навантажувальний тест (5, 10, 25 віртуальних користувачів):
  ```bash
  npm run test:load
  ```
